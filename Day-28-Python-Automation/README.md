
# Day 28 - Python Automation

## Project: Automatic File Organizer

This project organizes files into folders based on their
file extensions using Python.

## Concepts Used
- os module
- shutil module
- File and folder paths
- Creating directories
- File extensions
- Conditional statements
- Exception-safe duplicate handling

## How to Run

1. Install Python 3.
2. Open a terminal in this project folder.
3. Run:

   python file_organizer.py

4. Enter the path of a test folder.

## Example

Before:
- photo.jpg
- notes.txt
- report.pdf

After:
- JPG Files/photo.jpg
- TXT Files/notes.txt
- PDF Files/report.pdf

## Learning Goal

Learn how Python can automate repetitive file-management tasks.
