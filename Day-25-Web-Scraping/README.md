# Day 25 — Web Scraping with Python 🌐

Part of my 30 Days of Python Challenge.

## Topics Covered
- HTTP requests using `requests`
- HTTP status codes
- HTML parsing with BeautifulSoup
- Finding HTML elements
- Extracting text and links
- Saving scraped data into CSV

## Files
1. `basic_request.py`
2. `scrape_quotes.py`
3. `scrape_links.py`
4. `save_quotes_csv.py`

## Installation

```bash
python -m pip install requests beautifulsoup4
```

## Run the Programs

```bash
python basic_request.py
python scrape_quotes.py
python scrape_links.py
python save_quotes_csv.py
```

The examples use Quotes to Scrape, a practice website for learning web scraping.

## Learning Goal
To understand how to collect publicly available web data and prepare it for data analysis.
