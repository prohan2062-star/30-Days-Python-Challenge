# Day 7 - Python Lists

## Topics Covered
- Creating and accessing lists
- List indexing and slicing
- Updating list elements
- Adding elements using `append()` and `insert()`
- Removing elements using `remove()` and `pop()`
- Sorting and reversing lists
- Built-in functions: `len()`, `sum()`, `max()`, `min()`

## Programs
1. `list_basics.py` - List creation, indexing, slicing, and updating.
2. `list_operations.py` - Adding, removing, sorting, and reversing elements.
3. `list_practice.py` - Student Marks Analyzer mini project.

## What I Learned
Python lists allow us to store multiple values in a single variable. Lists are mutable, which means their elements can be changed after creation.
