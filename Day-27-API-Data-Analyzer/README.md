# Day 27 — API Data Analyzer 🌐📊

A Python mini project built as part of my 30 Days of Python Challenge.

## Features
- Fetches posts from a public testing API
- Processes JSON responses
- Counts posts per user
- Identifies the longest post title
- Exports post data to CSV
- Saves summary statistics to JSON
- Handles network and data errors

## Technologies
- Python
- Requests
- JSON
- CSV
- Collections Counter

## Installation

```bash
python -m pip install requests
```

## Run the Project

```bash
python api_data_analyzer.py
```

An internet connection is required to fetch the API data.

## API
JSONPlaceholder: https://jsonplaceholder.typicode.com/posts

## Learning Goal
To practice API integration, data processing, and report generation using Python.
