
# Day 29 - Python Expense Tracker

## About
A menu-driven Python application to record and analyze
daily expenses using CSV file storage.

## Features
- Add daily expenses
- View all recorded expenses
- Calculate total spending
- View category-wise expenses
- Store records in a CSV file
- Validate expense amounts

## Python Concepts
- Functions
- Loops and conditional statements
- CSV file handling
- Date handling
- Dictionaries and lists
- Exception handling

## How to Run

1. Install Python 3.
2. Open a terminal in this folder.
3. Run:

   python expense_tracker.py

4. Select an option from the menu.

## Files
- expense_tracker.py: Main application
- expenses.csv: Created automatically to store expenses

## Learning Goal
Practice Python programming by building a useful,
real-world expense management application.
