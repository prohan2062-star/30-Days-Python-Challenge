# Day 24 — Student Data Analysis 📊

A mini project built with Python and Pandas as part of my 30 Days of Python Challenge.

## Project Features
- Read student data from CSV
- Calculate individual student averages
- Assign grades based on average marks
- Calculate subject-wise averages
- Identify the top-performing student
- Filter students based on average marks
- Export analysis results to CSV

## Technologies Used
- Python
- Pandas
- CSV

## How to Run
1. Install Pandas: `python -m pip install pandas`
2. Keep `students.csv` and `student_analysis.py` in the same folder.
3. Run: `python student_analysis.py`
4. Open `student_analysis_results.csv` to view the results.

## Learning Outcome
Applied Python and Pandas concepts to analyze student performance and extract useful insights.
