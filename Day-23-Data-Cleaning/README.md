# Day 23 — Data Cleaning with Pandas 🐍

Part of my 30 Days of Python Challenge.

## Topics Covered
- Detecting missing values
- Filling missing data using mean and median
- Removing duplicate rows
- Cleaning text columns
- Converting data types
- Renaming columns
- Filtering and sorting datasets
- Exporting cleaned CSV files

## Files
1. `messy_data.csv` — Sample dataset with missing values and duplicates
2. `clean_data.py` — Cleans the dataset
3. `data_cleaning_practice.py` — Filters, sorts, and analyzes the cleaned data

## How to Run
1. Install Pandas: `python -m pip install pandas`
2. Run `clean_data.py`
3. Run `data_cleaning_practice.py`

Run both scripts from this folder so the CSV files are found correctly.

## Learning Goal
To prepare reliable datasets for Data Analysis and Machine Learning.
