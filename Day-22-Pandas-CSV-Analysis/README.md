# Day 22 — Pandas CSV Analysis 🐍

Part of my 30 Days of Python Challenge.

## Topics Covered
- Reading CSV files with `read_csv()`
- Exploring datasets with `head()` and `info()`
- Detecting missing values with `isnull()`
- Handling missing values with `fillna()`
- Filtering rows using conditions
- Calculating averages and summary statistics
- Exporting data with `to_csv()`

## Files
1. `students.csv` — Sample student dataset
2. `read_csv.py` — Loads and explores the dataset
3. `clean_data.py` — Handles missing values
4. `data_analysis.py` — Analyzes student performance

## How to Run
1. Install Pandas: `python -m pip install pandas`
2. Run `read_csv.py`
3. Run `clean_data.py`
4. Run `data_analysis.py`

Run all scripts from this folder so the CSV files are found correctly.

## Learning Goal
To develop practical data cleaning and analysis skills for Data Science and Machine Learning.
