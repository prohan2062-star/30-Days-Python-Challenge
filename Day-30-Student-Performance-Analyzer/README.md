
# Day 30 - Student Performance Analyzer

## Project Overview
A Python capstone project that analyzes student marks,
calculates percentages and grades, and generates a CSV report.

## Features
- Read student data from CSV
- Calculate total marks
- Calculate percentage
- Assign grades
- Identify Pass or Fail students
- Calculate class average
- Generate report.csv automatically

## Python Concepts Used
- Variables and data types
- Lists and dictionaries
- Functions
- Loops and conditions
- CSV file handling
- Exception handling

## How to Run

1. Make sure Python 3 is installed.
2. Keep students.csv and student_analyzer.py in the same folder.
3. Open the terminal.
4. Run:

   python student_analyzer.py

5. Check the generated report.csv file.
